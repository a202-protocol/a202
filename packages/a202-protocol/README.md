# a202

A202, the Verifiable Agreement Protocol for Agent-Led Commerce: an open,
carrier-neutral specification of commercial authority, negotiation state, and
verifiable conformance for transactions between independent organisations,
including transactions conducted on their behalf by software agents.

- Specification: https://github.com/a202-protocol/a202
- Documentation: https://a202.org
- Schemas: https://schemas.a202.org

**The JavaScript SDK has not been published yet.** This package holds the
name for the protocol project and exports the protocol identifiers only. The
specification's reference implementation is currently Python, in the
repository above.
